# 吧内列表返回位置修复

基于 `2885b2aabbbf47aba7bf12b1cd7cbc03b1f5ec15`（4.0.0-beta.1）。

## 问题与修改

从吧内列表进入帖子后返回，存在列表回到顶部的反馈。列表数据和吧规标题分别从默认空值异步恢复，可能产生中间布局；回顶事件还会被仍在订阅的后台页面接收。此前未在未修改版本上建立稳定复现，因此这些是修复针对的代码风险，不能认定为所有跳顶情况的已证实原因。

- 吧页面及帖子列表直接订阅完整 StateFlow 状态，首次组合使用当前缓存，避免空列表和标题分别恢复。
- 帖子列表 key 使用已去重的帖子 ID，避免列表顺序变化时 key 随下标变化。
- 全局回顶及吧内回顶处理仅在导航页面生命周期为 RESUMED 时执行。

## 构建与验证

本地使用 JDK 21、Gradle 8.5、Android SDK 34；Gradle Wrapper 从 8.2 更新到 8.5，以支持此 JDK。测试版 versionCode 为 390101，versionName 为 4.0.0-scrollfix-test.1。

```sh
./gradlew :app:testDebugUnitTest :app:assembleRelease
```

Release 编译、发布 lint、项目现有单元测试通过。现有单元测试不构成界面回归证据。

在小米 13、HyperOS 3 / Android 16 上安装测试版后，同一吧内列表连续 4 次打开帖子并返回，5 处可比内容的屏幕坐标每次均保持一致；其中一次先滚动帖子正文再返回。未覆盖所有吧、所有刷新组合或进程被系统回收后的恢复。
